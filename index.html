Cálculo de L para |V| deseado

  1. ω = 2πf rad/s
  2. |Y| = Iₛ / |V| mS
  3. G = 1 / R mS
  4. B_L = √(|Y|² − G²) mS
  5. X_L = 1 / B_L Ω
  6. L = X_L / ω mH

Con estos datos |Y| ≤ G: ningún inductor alcanza esa tensión.
